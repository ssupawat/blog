## ปัญหา

เวลาเราเขียนโค้ดแล้วต้องคอมเมนต์อธิบาย ควรใช้ภาษาไทยหรือภาษาอังกฤษ?

- **ภาษาไทย** — อ่านง่ายสำหรับคนไทย แต่อาจพิมพ์ยากถ้าต้องสลับภาษากับโค้ด
- **ภาษาอังกฤษ** — เป็นสากล คนทั้งโลกอ่านได้ แต่คนไทยที่อังกฤษไม่แข็งแรงอาจลำบาก

## คำตอบของผม

ใช้ภาษาอังกฤษสำหรับคอมเมนต์ในโค้ด เพราะโค้ดมันเป็นภาษาอังกฤษอยู่แล้ว การสลับภาษาไปมาทำให้เสียสมาธิ

```python
# This makes more sense
def calculate_thing(x: int) -> int:
    return x * 2
```

But for README files, write in both Thai and English.
